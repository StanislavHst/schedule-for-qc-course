# Чеклісти для тестування

## Модуль: Розміщення пари на конкретний час/день у розкладі (адмін-панель).

### Функціональність
- [ ] Вибір академічної групи завантажує лише відповідні пари
- [ ] Список пар відображає тільки ті, що належать обраній групі
- [ ] Клік на пару активує режим вибору та підсвічує доступні слоти
- [ ] Відображаються тільки ті слоти, де відсутні конфлікти
- [ ] Drag & drop пари на валідний слот дозволяє розміщення
- [ ] Після вибору слоту з’являється можливість вибору типу заняття
- [ ] Вибір типу заняття (лекція/семінар/лабораторна) є обов’язковим
- [ ] Після успішного збереження пара відображається у відповідному слоті
- [ ] Оновлення розкладу відбувається без перезавантаження сторінки

### Негативні сценарії
- [ ] Неможливо розмістити пару в слот, де викладач вже зайнятий
- [ ] Неможливо розмістити пару в слот, де аудиторія вже зайнята
- [ ] Drag & drop на зайнятий слот показує помилку та не дозволяє drop
- [ ] При конфлікті відображається повідомлення про конфлікт
- [ ] Неможливо підтвердити розміщення без вибору типу заняття
- [ ] При зміні групи скидається вибрана пара
- [ ] Неможливо взаємодіяти зі слотами без вибору пари

### UI/UX
- [ ] Підсвічування доступних слотів є зрозумілим та помітним
- [ ] Конфліктні слоти мають візуальне відображення (disabled/інший колір)
- [ ] Drag & drop має візуальний фідбек (перетягування, підсвітка)
- [ ] Повідомлення про помилки є зрозумілими для користувача
- [ ] Після успішного розміщення інтерфейс оновлюється без затримок
- [ ] Кнопка "Підтвердити" активна тільки при валідному стані
- [ ] Скасування дії повертає систему у стабільний стан без артефактів
